# Just Notes v1.5.0

Release date: 2026-05-24

## Summary

Just Notes v1.5.0 aligns the app language behavior with Android system language settings, improves ColorNote-like text note editing ergonomics, and includes regression fixes validated on the Android Studio emulator.

## User-Facing Changes

- Follow Android system language by design. Just Notes no longer exposes an in-app language picker; users change the app language through Android system or app language settings.
- Improve text note editing ergonomics. Tapping a note title or content enters editing naturally, while long-press continues to support multi-select actions.
- Polish text note and link editing behavior.
- Keep quick insert behavior aligned with focus-writing mode.

## Fixes

- Fixed emulator regression where long-pressing the title text did not reliably enter multi-select.
- Fixed quick insert state so inserted content keeps the editor in focus-writing mode.
- Stabilized focused UI regression tests with unique test data and more reliable assertions.
