# Agent A - Steve Jobs-Style Text Note Review V2

Date: 2026-06-15

Role: review the Just Notes text-note experience from a Steve Jobs lens: reduce friction, let the content lead, and remove visual noise from everyday writing and reading.

## 1. 新增文字記事要少一步

問題：新增文字記事要先點「+」再選選單。

為什麼重要：靈感捕捉多一步，就多一次流失。

具體修改：FAB 單點直接開「文字記事」並聚焦正文；長按或小箭頭才開清單、繪圖、OCR。

## 2. 閱讀頁要讓內容先出現

問題：閱讀頁在正文前顯示資料夾、更新時間、已儲存、無提醒等管理資訊。

為什麼重要：取回文字時，內容應該先到眼前。

具體修改：閱讀頁預設只突出標題＋正文；只有有提醒或儲存失敗才顯示狀態，其餘放進「詳細」或更多選單。

## 3. 首頁筆記卡片要降噪

問題：首頁卡片同時露出類型、資料夾、建立/更新、置頂/移動/刪除。

為什麼重要：找筆記時噪音太多，掃描速度變慢。

具體修改：卡片預設只留標題、2 行預覽、相對更新時間；管理動作移到長按/更多，搜尋結果顯示命中前後文並高亮。

## Product Direction

Just Notes 的文字記事下一步不應該是繼續堆功能，而是把「立刻寫、舒服讀、快速找回」做到更純粹。
