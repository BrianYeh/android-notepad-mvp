# Just Notes 繪圖記事 v3 手動測試說明

日期：2026-06-20

## 這版要測什麼

v3 的重點是讓「已經有筆畫的繪圖記事」重新打開時，直接回到畫布，而不是先看到標題、資料夾、提醒、分享按鈕那一頁。

這讓繪圖記事更像繪圖工具：你點開一張已畫過的圖，就直接看到圖。

## 功能重點

### 1. 有筆畫的繪圖記事重新開啟會先進全螢幕畫布

測試步驟：

1. 新增一則繪圖記事。
2. 在畫布上畫一筆。
3. 退出全螢幕，輸入標題。
4. 返回首頁。
5. 從首頁點開這則繪圖記事。

預期結果：

- 會先看到全螢幕畫布。
- 畫布上方會顯示標題與儲存狀態。
- 右上角 Details 三點按鈕仍然存在。

### 2. Details 仍可回到一般詳細模式

測試步驟：

1. 接續上一項，在全螢幕畫布右上角點 Details 三點按鈕。

預期結果：

- 會回到一般詳細模式。
- 可以看到標題欄。
- 可以看到分享 PNG 與匯出 PNG 控制項。
- 原本的筆畫仍然存在。

### 3. 只有標題、沒有筆畫的繪圖記事維持詳細模式

測試步驟：

1. 新增一則繪圖記事。
2. 不畫任何筆畫。
3. 輸入標題。
4. 返回首頁。
5. 再點開這則繪圖記事。

預期結果：

- 不會直接進全螢幕畫布。
- 會先看到標題欄與一般詳細模式。
- 方便繼續修改標題、資料夾、提醒等 metadata。

### 4. 新增空白繪圖仍維持 v2 的乾淨畫布

測試步驟：

1. 新增一則繪圖記事。
2. 先不要輸入標題，也不要畫筆畫。

預期結果：

- 會直接進入乾淨全螢幕畫布。
- 不顯示 `Untitled drawing`。
- 不顯示儲存狀態。
- 右上角 Details 仍可進一般詳細模式。

### 5. 空白草稿返回清理仍安全

測試步驟：

1. 新增一則繪圖記事。
2. 不輸入標題、不畫筆畫。
3. 按返回退出全螢幕。
4. 再按返回回首頁。

預期結果：

- 空白草稿會被清掉。
- 首頁不會留下空白繪圖卡片。

## 不屬於這版的項目

這版沒有更動：

- PNG 分享 / 匯出格式。
- 繪圖 JSON 儲存格式。
- 首頁縮圖渲染方式。
- 多頁畫布、縮放、平移。
- 新增 fullscreen bottom sheet。
