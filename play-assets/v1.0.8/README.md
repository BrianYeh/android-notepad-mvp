## Provenance and restrictions

- The icon is a deterministic raster rendering of `app/src/main/res/drawable/ic_launcher_foreground.xml` on its existing white launcher background.
- The feature graphic was created with the built-in image-generation tool using this final prompt: warm paper-yellow Play feature graphic, organized note cards, subtle pencil motif, exact text `Just Notes`, no badge, price, ranking claim, trademark, device frame, or watermark.
- Screenshots contain no personal account identifier, notification content, external device frame, or real note content.
- Feature graphic and screenshots are opaque RGB PNG files. The icon is an opaque RGBA PNG suitable for the 32-bit icon requirement.
