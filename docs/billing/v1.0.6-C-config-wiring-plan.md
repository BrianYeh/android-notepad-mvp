## 2. Android Wiring

The checked-in `gradle.properties` supplies the non-secret Web OAuth client ID
through `justNotes.googleWebClientId`.

`justNotes.backendBaseUrl` is now the verified dev origin:

`https://just-notes-entitlement-api-dev-1025325431669.asia-east1.run.app`

The Android runtime remains GET-only. Configuring this origin enables signed-in
`GET /v1/entitlement` refreshes but does not add a purchase-token POST path,
show the purchase button, or make `POST /v1/billing/verify` granting.

The Android Gradle script rejects a non-empty backend URL unless it is an HTTPS
origin without a path, embedded credentials, query, or fragment. It also rejects a
non-empty Web client ID unless it has the Google Web OAuth client ID form
`*.apps.googleusercontent.com`.

Runtime validation repeats the fail-closed checks before an ID token can be
sent over the network:

| Android configuration | Result |
| --- | --- |
| Blank backend URL | `BackendEntitlementFetchResult.Disabled` |
| HTTPS URL plus valid Web client ID | Eligible for `GET /v1/entitlement` after sign-in |
| HTTP, malformed, path-bearing, credential-bearing, query-bearing, or fragment-bearing URL | Failure before opening a connection |
| Non-empty backend URL plus missing or malformed Web client ID | Failure before opening a connection |
| Missing ID token | `NotSignedIn`; no entitlement is applied |

The deterministic HMAC inputs are pinned to numeric Secret Manager versions.

IDs before accepting an identity. The issuer allowlist and exact `aud` equality
check remain authoritative. Production startup includes the same validation,
so a revision with unusable authentication never reports a healthy state.

## 4. Current Non-Granting Boundary

The production module now creates official Google Cloud and Android Publisher
adapters using Application Default Credentials:

- Secret Manager supplies versioned HMAC material without placing payloads in environment variables;
- Cloud KMS encrypts and decrypts purchase tokens while Firestore stores only ciphertext metadata;
- Firestore provides entitlement reads/writes and transactional token-hash ownership binding;
- Android Publisher supports `purchases.subscriptionsv2.get` and subscription acknowledgement;
- no service-account key or downloadable credential is used;
- `POST /v1/billing/verify` returns HTTP `202`, `hasPremium=false`,
  `VerificationPending`, and `POST_VERIFY_DISABLED`;
- RTDN returns `501 rtdn_not_enabled`;
- Android release entitlement remains backend-verified only;
- `justNotes.allowClientOnlyBillingEntitlement` remains `false` by default and
  is forced to `false` for release builds.

Config wiring must not be treated as authorization to replace any of these
boundaries.
