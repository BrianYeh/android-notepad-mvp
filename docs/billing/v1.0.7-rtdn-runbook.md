## Deployment and IAM

All commands use project `gen-lang-client-0599059254` and region `asia-east1`.

```bash
gcloud builds submit backend \
  --tag asia-east1-docker.pkg.dev/gen-lang-client-0599059254/cloud-run-source-deploy/just-notes-rtdn-dev:<commit>

gcloud run deploy just-notes-rtdn-dev \
  --image asia-east1-docker.pkg.dev/gen-lang-client-0599059254/cloud-run-source-deploy/just-notes-rtdn-dev:<commit> \
  --region asia-east1 \
  --service-account just-notes-entitlement-api-dev@gen-lang-client-0599059254.iam.gserviceaccount.com \
  --env-vars-file backend/cloudrun/rtdn-dev.env.yaml \
  --concurrency 20 --max-instances 2 --timeout 30s \
  --no-allow-unauthenticated

gcloud iam service-accounts create just-notes-rtdn-push-dev \
  --display-name "Just Notes RTDN Push Dev"

gcloud run services add-iam-policy-binding just-notes-rtdn-dev \
  --region asia-east1 \
  --member serviceAccount:just-notes-rtdn-push-dev@gen-lang-client-0599059254.iam.gserviceaccount.com \
  --role roles/run.invoker

gcloud iam service-accounts add-iam-policy-binding \
  just-notes-rtdn-push-dev@gen-lang-client-0599059254.iam.gserviceaccount.com \
  --member serviceAccount:service-1025325431669@gcp-sa-pubsub.iam.gserviceaccount.com \
  --role roles/iam.serviceAccountTokenCreator
```

The private service IAM policy must never contain `allUsers` or `allAuthenticatedUsers`.

## Pub/Sub reliability resources

```bash
gcloud pubsub topics create just-notes-rtdn-dev
gcloud pubsub topics create just-notes-rtdn-dead-letter-dev
gcloud pubsub topics add-iam-policy-binding just-notes-rtdn-dev \
  --member serviceAccount:google-play-developer-notifications@system.gserviceaccount.com \
  --role roles/pubsub.publisher
gcloud pubsub subscriptions create just-notes-rtdn-dead-letter-inspect-dev \
  --topic just-notes-rtdn-dead-letter-dev --message-retention-duration 7d

gcloud pubsub subscriptions create just-notes-rtdn-push-dev \
  --topic just-notes-rtdn-dev \
  --push-endpoint <private-origin>/v1/play/rtdn \
  --push-auth-service-account just-notes-rtdn-push-dev@gen-lang-client-0599059254.iam.gserviceaccount.com \
  --push-auth-token-audience <private-origin> \
  --min-retry-delay 10s --max-retry-delay 600s \
  --dead-letter-topic just-notes-rtdn-dead-letter-dev \
  --max-delivery-attempts 10 \
  --message-retention-duration 7d
```

Grant the Pub/Sub service agent subscriber permission on the push subscription and publisher permission on the dead-letter topic when the CLI reports the standard dead-letter IAM warning.
