# Just Notes v1.0.8 English-Market Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish an accurate English store listing and expand the existing Just Notes 1.0.8 Production release from Taiwan to the United States, Canada, United Kingdom, Australia, New Zealand, Singapore, and Hong Kong after explicit approval of Play Console's local subscription prices.

**Architecture:** This is a configuration and content rollout, not an application release. The existing AAB, Android code, Billing backend, Firestore/KMS data model, acknowledgement flow, and RTDN service remain unchanged; only the English listing, legal price wording, subscription regional availability/prices, and Production countries change.

**Tech Stack:** Google Play Console, Google Play Billing subscriptions, GitHub Pages static HTML, WSL Git, HTTPS verification.

## Global Constraints

- Keep version name `1.0.8` and version code `6`; do not upload an AAB.
- Keep package `com.brianyeh.justnotes` and product `just_notes_premium`.
- Keep base plans `monthly` and `annual`.
- Keep `trial10d` monthly-only and eligibility controlled by Google Play.
- Keep annual without a trial.
- Keep Taiwan available at TWD 33 monthly and TWD 330 annual.
- Add only United States, Canada, United Kingdom, Australia, New Zealand, Singapore, and Hong Kong.
- Do not deploy Android or backend code, modify Cloud Run/IAM, or modify RTDN.
- Use WSL for every Git status, diff, add, commit, and push command.
- Never stage `.codex-remote-attachments/`, `Doc/billing/`, or `docs/superpowers/plans/2026-07-11-v1.0.7-purchase-orchestration.md`.
- Do not submit regional prices or public country availability without an action-time confirmation.
