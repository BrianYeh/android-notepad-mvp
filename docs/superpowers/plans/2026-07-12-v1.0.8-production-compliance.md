# Just Notes v1.0.8 Production Compliance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a production-compliance-ready Just Notes 1.0.8 build for Taiwan with public legal pages, safe Google reviewer Premium access, authenticated account deletion, complete Play metadata, and Managed publishing.

**Architecture:** Preserve the existing Billing, entitlement, KMS, Firestore, acknowledgement, and private RTDN paths. Add two isolated authenticated read/control capabilities: a fail-closed `ReviewerGrant` evaluated only by `GET /v1/entitlement`, and a terminal-state-gated account deletion endpoint used by a GitHub Pages deletion page. Android accepts the new backend-authoritative source, opens the three public compliance URLs, and otherwise keeps the purchase flow unchanged.

**Tech Stack:** Kotlin/JVM 17, Ktor 2.3.12, Firestore, Secret Manager, Google ID token verification, Android Kotlin/Compose, JUnit/Ktor test host, GitHub Pages/Actions, Google Identity Services, Google Play Console, Cloud Run.

## Global Constraints

- Release `versionName = "1.0.8"` and `versionCode = 6`.
- Initial Production country/region is Taiwan only.
- Monthly remains TWD 33 with `trial10d` only for eligible users; annual remains TWD 330 with no trial.
- Do not refactor Billing or RTDN and do not change products, prices, base plans, offers, or trial configuration.
- Never commit, document, print, or log the reviewer username/password, raw email, Google ID token, Google subject, raw purchase token, ciphertext, or Secret Manager payload.
- Never create or download a service-account key or JSON credential file.
- Do not grant `allUsers` to the private RTDN service and do not weaken any existing IAM binding.
- Public API `/v1/rtdn` must remain HTTP 501; the private RTDN service remains private.
- GitHub Pages publishes only `site/`.
- Use Managed publishing before review submission.
- Sending changes for review and making the approved release public each require a fresh action-time user confirmation.
- Preserve unrelated user files and never stage generated crash logs, Gradle caches, raw screenshots containing personal data, or secrets.

```kotlin
package com.brianyeh.justnotes.backend.security

import java.util.Locale

fun interface EmailHashDeriver {
    fun derive(normalizedEmail: String): String
}

class HmacSha256EmailHashDeriver(
    private val secretProvider: SecretValueProvider,
) : EmailHashDeriver {
    override fun derive(normalizedEmail: String): String {
        require(normalizedEmail == normalizeGoogleEmail(normalizedEmail)) {
            "Email must be normalized before hashing."
        }
        val secret = secretProvider.currentSecret()
            ?: error("Email hash pepper is not configured.")
        return hmacSha256UrlSafe(secret.value, normalizedEmail)
    }
}

fun normalizeGoogleEmail(email: String): String = email.trim().lowercase(Locale.ROOT)
```
